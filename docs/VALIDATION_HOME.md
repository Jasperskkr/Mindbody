## 浏览器验证

使用应用内 Chromium 浏览器，测试地址为 `http://localhost:5174/`，与用户使用的 `http://127.0.0.1:5173/` 隔离。只在测试地址填写虚构内容，不读写、清理或截图日常地址的健康记录。

| 场景 | 实际结果 |
| --- | --- |
| 首次打开，当前日期无记录 | 显示“尚未记录”、填写引导、四项“未填写”，无模拟数据 |
| 只填睡眠 0 并保存，返回首页 | 睡眠显示 0 h；情绪、压力、精力、身体感受仍未填写 |
| 刷新和再次进入记录页 | 保留已保存的 0，未选量表没有默认值 |

## 手动验收

如已有重要当天记录，使用独立浏览器配置验收虚构样例，避免更新日常数据。长期使用请固定浏览器和地址；不要把 5174 的测试记录当作 5173 的日常记录。

1. 打开并刷新 `http://127.0.0.1:5173/`。开发服务未启动时运行 `pnpm dev:h5`。
2. 没有当天记录时：首页应提示尚未记录，所有项目为未填写；有记录则应显示已保存内容。
3. 点击“每日记录”，填写虚构例子：情绪 4、睡眠 7.5，精力留空，保存并看到成功提示。
4. 点“返回首页”：情绪显示较愉快、睡眠显示 7.5 h、精力显示未填写；不需额外保存首页。
5. 刷新首页，再进入记录页：两处已保存内容应一致。
6. 将睡眠改成 25 并尝试保存：应提示错误；返回首页时仍为之前成功保存的 7.5 h。
7. 把睡眠改成 0，成功保存后返回：应显示 0 h。清空某一量表并保存后，该项应显示未填写。
8. 切换 320px、390px 宽度检查无横向滚动；历史趋势仍占位，AI 周报仍禁用。

## 验证边界

- 读取失败、重试和异步请求次序由真实首页 setup 的内存替身测试覆盖，未改变用户浏览器权限或损坏实际存储。
- 未进行真实手机、Safari、微信小程序或原生 App 验证。
- 首页在出现或刷新时重读，不实现后台实时跨标签页同步、自动草稿或自动跨午夜更新；下一次显示会切换到本地当天日期。
- 没有新增备份、删除、导出、历史页面或存储迁移，旧记录的键和格式保持兼容。
