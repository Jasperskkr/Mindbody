本文保留首次表单交付时的结果；随后授权的首页联动已替换模拟概览，最新结果与验收步骤见 [首页联动验证](./VALIDATION_HOME.md)。

## 自动检查

- `pnpm check`：最终代码的类型检查、15 项 Node 内置测试、Web 生产构建全部通过，未增加依赖。
- `pnpm test`：15 项测试通过；12 项覆盖日期、校验与存储，3 项运行真实 Vue 页面 setup 代码并用内存存储替身验证失败反馈与重试。
- 覆盖：全空与纯空白、部分填写、缺失字段不补值、0 小时、24 小时、合法小数、非法文本与超范围、1–5 整数、非法日期、超长文本、保留 createdAt、更新 updatedAt、保留其他日期、读/写失败、同步异常、损坏和不兼容的存储格式。
- 页面测试覆盖读取失败时禁止保存、重试恢复、写入失败保留输入、成功提示随新输入清除、跨日后阻止误保存。
- 测试不访问真实浏览器存储、不调用后端，不使用真实健康记录。

## 你可以怎样手动验收

1. 打开 `http://127.0.0.1:5173/`，刷新首页，点击“每日记录”。服务未启动时运行 `pnpm dev:h5`。
2. 首次使用时不要填内容，直接保存，应提示至少填写一项；三个量表不能自动选择 3。
3. 只填写睡眠 `0`，保存并刷新，应仍显示 `0`；量表仍是“尚未填写”。
4. 填写虚构样例：情绪 4、压力 2、睡眠 7.5、身体感受“这是手动验收用的虚构记录”，精力留空。保存后刷新，应按原样回填。
5. 把睡眠改成 `25` 或 `abc` 再保存，应提示非法输入；刷新后应恢复上一次成功保存的 `7.5`。
6. 选择精力再点“清空”，保存并刷新，精力应仍为空。返回首页，概览应读取当前保存的记录，精力显示“未填写”；再进入记录页时内容仍在。
7. 在开发者工具中分别切换 320px、390px 宽度，检查无横向滚动，保存按钮可滚动到达。
8. 刷新后点击“返回首页”，应正常到首页；历史趋势仍占位，AI 周报不能操作。

提示：测试会保存到你当前浏览器当天的记录；若已有需要保留的记录，建议用独立浏览器配置或无痕窗口验收。无痕数据可能在关闭窗口后消失，不适合长期使用。

## 已知边界

- 未验证真实手机、微信小程序、原生 App、Safari；本轮仅完成移动宽度 Web 验证。
- 未实现自动草稿、删除、导出、跨标签页冲突合并。离开或刷新前未成功保存的输入可能丢失；多个标签同时保存同一天时，以最后成功保存为准。
- 本地存储未加密；不同浏览器、地址和端口互不共享，清理浏览器数据可能丢失记录。
- 本轮不提交、不推送、不部署，不开发下一项功能。

## 记录页入口故障修复

2026-11-19，在用户实际使用的 5173 服务上复现了“暂时无法打开记录页”。控制台提示“当前项目为单页面工程，不能执行页面跳转 api”，并出现路由对象缺失错误。虽然 `pages.json` 已包含新页面，长期运行的旧服务和浏览器仍使用单页运行环境；之前新启动的隔离测试服务未出现此问题。

已重启确认为本项目的 5173 开发服务并刷新原浏览器标签，再实际点击首页“每日记录”，确认显示“记下今天的自己”记录页标题。整个修复没有填写、保存、清理或导出记录，没有修改业务代码。README 已补充新增页面后的重启说明。
